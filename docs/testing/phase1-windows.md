# Phase 1 Windows 테스트 체크리스트

사이드바 도킹은 Windows에서만 동작하고, 개발 환경(Linux)에서는 직접 실행해 볼 수 없다. 아래 항목을 실제 Windows에서 확인한다.

## 준비

1. GitHub Actions의 최신 CI 실행에서 `ai-management-windows-nsis` 아티팩트를 받는다.
2. 압축을 풀고 `ai-management_*_x64-setup.exe`를 실행한다.
   - 서명이 없어서 "Windows의 PC 보호" 창이 뜬다 → **추가 정보 → 실행**
3. 트레이(작업 표시줄 오른쪽 아래)에 앱 아이콘이 생기는지 확인한다.

결과는 항목 번호와 함께 ✅ / ❌ + 한 줄 메모로 알려주면 된다. 화면 배율(100%·125%·150%)과 모니터 수도 같이 적어준다.

## A. 기본 도킹

| # | 해볼 것 | 기대 결과 |
|---|---|---|
| A1 | Windows Terminal을 열고 클릭 | 사이드바가 터미널 **오른쪽 바깥**에 붙고, 위아래 높이가 터미널과 같다. 아래 상태 표시줄에 "Windows Terminal 오른쪽에 붙음" |
| A2 | 터미널을 마우스로 끌어 이동 | 사이드바가 따라온다 (끊기거나 늦게 따라오면 메모) |
| A3 | 터미널을 화면 오른쪽 끝으로 붙임 | 사이드바가 터미널 **왼쪽**으로 넘어간다 |
| A4 | 터미널 최대화 | 사이드바가 터미널 오른쪽 안쪽에 **겹쳐서** 뜬다 |
| A5 | 터미널 크기 조절 | 사이드바 높이와 위치가 맞춰진다 |
| A6 | `cmd.exe`나 PowerShell을 예전 콘솔 창으로 실행 | "콘솔"로 붙는다 |
| A7 | VS Code 클릭 | VS Code 옆으로 옮겨간다 |
| A8 | Claude 데스크탑 클릭 | Claude 데스크탑 옆으로 옮겨간다 |

## B. 다른 앱과 겹침 순서

| # | 해볼 것 | 기대 결과 |
|---|---|---|
| B1 | 터미널이 활성인 상태 | 사이드바가 다른 창들 위에 보인다 |
| B2 | 브라우저 같은 다른 앱 클릭 | 사이드바는 터미널 옆에 남고, 브라우저가 **사이드바를 가린다** |
| B3 | 다시 터미널 클릭 | 사이드바가 다시 위로 올라온다 |
| B4 | 사이드바를 클릭 | 사이드바가 그대로 터미널 옆에 있고 사라지지 않는다 |
| B5 | Alt+Tab으로 앱 전환 | B2·B3과 같다 |

## C. 숨김 / 표시

| # | 해볼 것 | 기대 결과 |
|---|---|---|
| C1 | 터미널 최소화 | 사이드바도 사라진다 |
| C2 | 터미널 복원 | 사이드바가 다시 옆에 나타난다 |
| C3 | 가상 데스크톱 전환 (Win+Ctrl+→) | 사이드바가 터미널과 함께 사라진다 |
| C4 | 원래 데스크톱으로 복귀 | 다시 나타난다 |
| C5 | Win+D (바탕 화면 보기) | 사이드바가 보이지 않는다 |
| C6 | 터미널 닫기 | 사이드바가 화면 **오른쪽 가장자리**로 이동하고 "화면 가장자리" 표시 |
| C7 | `Ctrl+Alt+Space` | 사이드바 숨김 → 다시 누르면 나타남 |
| C8 | 사이드바 ✕ 버튼 | 숨겨진다 (앱은 트레이에 남아 있음) |
| C9 | 트레이 아이콘 왼쪽 클릭 | 보이기 / 숨기기 |
| C10 | 트레이 우클릭 → 종료 | 앱이 완전히 종료된다 |
| C11 | 터미널 최소화 상태에서 `Ctrl+Alt+Space` | 사이드바가 화면 가장자리에 나타난다 |
| C12 | 앱을 한 번 더 실행 | 새 창이 생기지 않고 기존 사이드바가 나타난다 |

## D. 버튼

| # | 해볼 것 | 기대 결과 |
|---|---|---|
| D1 | 자석 버튼 끄기 | "도킹 꺼짐". 사이드바를 끌어서 아무 데나 둘 수 있다 |
| D2 | 자석 버튼 다시 켜기 | 활성 터미널 옆이나 화면 가장자리로 돌아간다. 트레이 메뉴 체크 표시도 같이 바뀐다 |
| D3 | 핀 버튼 켜고 브라우저 클릭 | 사이드바가 브라우저 위에 계속 보인다 |
| D4 | 사이드바 안의 탭 클릭 | 클릭이 잘 되고, 클릭해도 사이드바가 사라지거나 튀지 않는다 |

## E. 특수 상황

| # | 해볼 것 | 기대 결과 / 메모할 것 |
|---|---|---|
| E1 | 배율이 다른 모니터 두 대 사이로 터미널 이동 | 사이드바 폭이 각 모니터 배율에 맞게 바뀌고, 위치가 어긋나지 않는다 |
| E2 | 관리자 권한으로 연 터미널 | 붙는지, 따라오는지 메모 (권한 차이로 안 될 수 있음) |
| E3 | Win+← / Win+→ 화면 분할 | 분할된 터미널 옆에 맞게 붙는다 |
| E4 | Windows Terminal 창 두 개 사이 전환 | 활성화한 창으로 옮겨간다 |
| E5 | 사용 중 CPU / 메모리 | 작업 관리자에서 ai-management 프로세스 메모리 사용량을 적어준다 |
